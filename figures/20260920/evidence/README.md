# v27 树数检查：不重训
结论：500→1000棵树仍在部分信号效率点减少检验样本中的sideband背景，但收益明显小于训练样本；当前结果支持暂时保留1000棵，不据此认定500棵更好。
完整tag：`X_pb23_v27_fid18_9v9_rw0_xgb_v1`。仅使用现有模型的前300/500/750/1000棵树，没有重训、修改selection、选择新WP或覆盖原始产物。
## 已核对的复现
- MC/DATA scored ROOT沿原筛选和顺序恢复，按原75%/25%、random_state=42划分。train：93312 MC、38925 sideband；test：30925 MC、13154 sideband。
- 1000棵树的分数与保存Prediction逐条一致（最大差0）；train/test AUC分别为0.9214453444351903/0.8601808116803092，完整ROC数组与原记录一致。
- 104行结果由保存分数独立重算通过；原模型、ROOT、metadata和所用源码的前后SHA256均未变。scaler手工加权均值与保存值差约2.83e-10，属于浮点数值检查容差内；实际预测与ROC完全复现。

## 比较口径与用途
- 沿用原13个目标信号效率；每种树数、每个train/test样本分别从该样本的pThat加权MC计算阈值，背景unit weight，严格score > threshold。比较同一目标效率下的识别能力，不是在test应用train阈值的部署检验。
- 离散候选导致实际信号效率略低于目标；全部点最大短缺0.2183个百分点，各点实际值在CSV。30%和40%附近500/1000比较的实际效率差分别约+0.031/-0.014个百分点。
- 源训练没有保存原始生产ROOT哈希，本轮冻结现有compact artifacts，并以完整分数/ROC复现确认样本重建。未验证独立event划分；当前仍是原candidate级划分。
- 此次检查帮助判断后续树的作用，不自动更改模型或冻结最终树数。
